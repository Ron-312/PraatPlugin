## What's new in 1.6

### Praat 7 support
- Praat 7 blocks scripts from writing files unless it's started with `--FULL-TRUST`, so with Praat 7 no script could return audio. The plugin now passes the flag when it detects Praat 7 or newer (Praat 6 is unchanged). Scripts you run therefore get full file access.

### 404 of 459 community scripts verified
- Every script in the AudioTools library was run through real Praat. **404 work** (up from 11 on Praat 7). Per-script results are in [docs/script-compatibility.md](https://github.com/Ron-312/PraatPlugin/blob/main/docs/script-compatibility.md).
- Form parser reads the newer colon syntax (`real: "Delay (s)", "0.25"`, `optionMenu:`…), numeric defaults with hints, and padded `endform` lines.

### Two-Sound scripts
- Cross-synthesis, morphing, convolution, pitch-contour transfer and more: a **LOAD SOUND B** row appears for scripts that read a second Sound.

### Folder pickers
- Corpus scripts that work on a folder of clips get a **BROWSE** button. Runs that would open a Praat file dialog are refused with a clear message instead of hanging for 30 s.

### Script tags
- The script browser tags scripts as `2 SOUNDS`, `FOLDER`, `DIALOG`, `WINDOW` or `UNSUPPORTED`, and shows why a script can't run.

### Quieter runs
- "Play…" and "…editor" options start switched off, so Praat no longer plays through your speakers during a run.

### Tests
- Unit tests for the form parser, script invocation and script capabilities, plus a `[compat]` suite that runs a whole script library through Praat. The test target builds again.
